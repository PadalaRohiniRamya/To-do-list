# FocusFlow — To-Do List Application

A responsive productivity dashboard built with HTML5, CSS3 and vanilla JavaScript.

## Features

- Create, edit and delete tasks
- Mark tasks complete/incomplete
- Search tasks instantly
- Filter All / Active / Completed
- Sort by newest, due date, priority or title
- High / Medium / Low priorities
- College / Work / Project / Personal / Other categories
- Due dates and overdue highlighting
- Optional notes
- Productivity percentage and progress ring
- Daily productivity streak
- Dark/light mode
- Keyboard shortcuts
- Accessible labels and keyboard-friendly controls
- Responsive mobile-first layout
- LocalStorage persistence
- No backend required
- GitHub Pages ready

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Browser LocalStorage
- GitHub Pages

## Run locally

Open `index.html` using VS Code Live Server or any static web server.

## Deployment

This project can be deployed directly with GitHub Pages:
Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Accessibility

The application includes semantic sections, labels, ARIA states, visible focus styles, keyboard shortcuts, reduced-motion support and responsive layouts.

## Data

Tasks are stored locally in the browser using `localStorage`. No personal task data is sent to a server.
